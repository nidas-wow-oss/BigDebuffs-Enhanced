# BigDebuffs Enhanced

Big crowd control, stance and interrupt icons on unit frame portraits for World of Warcraft 3.3.5a (WotLK).

Based on the **BigDebuffs** WotLK backport (original by **Jordon**, backport by **Konjunktur**). All credit for the original addon goes to its authors.

## What this version does differently

- Much lower memory use: the options panel is built only when you open it, spell tables are shared instead of copied, and unused events are turned off.
- Smoother: less work per aura update.
- Bug fixes, with no features removed.

## Installation

1. Download this repository (**Code → Download ZIP**).
2. Copy the `BigDebuffs` folder into `World of Warcraft/Interface/AddOns/`.

## Usage

`/bd` or `/bigdebuffs` opens the options.
